# craftialabs: intro espacial

Landing en 3D (Three.js incluido en `vendor/`, sin dependencias externas salvo la tipografía de Google Fonts).

## Desplegar en Coolify
1. New Resource, Public/Private Repository, rama `main`.
2. Build Pack: **Dockerfile**. Puerto: **80**.
3. Dominios: `https://craftialabs.com,https://www.craftialabs.com`.
4. DNS: registros A de `@` y `www` hacia la IP del VPS.

## Editar textos
Descripciones de cada servicio: constante `DESC` en `index.html`. Botones de contacto: busca `#contacto`.
